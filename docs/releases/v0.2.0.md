Cadanraw 0.2.0 turns the canvas into a space for planning, collecting references and working together.

### New canvas blocks

- **Kanban:** editable columns and tasks, drag tasks by their handle or move them with the arrow controls. Add columns, remove empty columns, and keep task changes in board history.
- **Attachments:** store reference files inside the board, add a caption, replace or download the original. Up to 4 MB per file; attachments travel with `.excalidraw` exports and shared sessions.
- **Board cards:** connect related canvases in your local desktop library and open them directly from the canvas.
- Notes, checklists, tables, calendars and website/video cards with editable titles, colors and details.

### A calmer workspace

- Home with grid/list browsing, board previews, search, sorting and pinned boards.
- Persistent nested folders shared by Home and the sidebar, with drag-and-drop moves and a Move to folder action.
- Visible Excalidraw import buttons; imported files are copied into Cadanraw's managed storage.
- A dark dot-grid canvas, consistent context menus and borderless text editing. Text-sized fields leave blank space available for grabbing cards.
- Link cards fetch page titles and thumbnails; YouTube links support previews and playback.

### Collaboration and agents

- Self-hosted browser collaboration with edit/view links and live cursors. Hosts can end sessions and revoke links; room data persists across relay restarts.
- Opt-in, token-protected local MCP access. Read-only by default, with an explicit option to let agents add content.
- The relay source and Docker setup are included in the repository. A standalone relay bundle is attached to this release; run it with Node 20 and follow `docs/COLLABORATION.md`.

### Before updating

- Existing boards and versions are preserved; the library database adds folder metadata automatically.
- Custom blocks retain the working embeddable editor, including Excalidraw's small blue link icon. Custom block content is preserved in `.excalidraw` exports, but PNG/SVG exports do not yet render their HTML contents.
- Board cards refer to your local library; browser guests do not gain access to other local boards.
- Public collaboration needs your own reachable HTTPS relay. It is not hosted automatically. This initial relay is intended for small trusted groups; simultaneous edits to the same block resolve as a whole block.
- Desktop installers are unsigned. macOS may require right-click Open; Windows may show SmartScreen on first launch.
