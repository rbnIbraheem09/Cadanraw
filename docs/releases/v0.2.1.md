Cadanraw 0.2.1 gives agents real control over your boards and fixes trackpad panning over blocks.

### Agents (MCP)

- **Manage canvases:** agents can create, open, rename and delete canvases, not just add to the one that's open. Deleted canvases go to the system trash.
- **Fix their own mistakes:** move, resize, restyle, re-text and delete elements by ID. Every agent edit can be undone in the app.
- **Images:** add images from a URL, a data URL or a local file path, with optional position and size.
- **Custom blocks:** add notes, checklists, tables, calendars, Kanban boards, link and board cards with their content filled in, and edit that content later.
- **Screenshots:** agents can see the board as it looks in the app, rich blocks included. A screenshot zooms to fit everything (or chosen elements) and crops to the content, and it reports which part of the board it shows.
- **Leaner reads:** `read_canvas` can read any canvas, includes the visible area and your selection, and summarizes embedded image data so large boards stay readable.
- The editing option is now labelled **Allow agents to edit boards**. Read-only access still can't change anything.

### Fixes

- Two-finger trackpad panning and pinch-zoom now keep working when the cursor passes over a block, just like native shapes. A block you're editing still scrolls its own overflowing content first.
- Pasting an image URL that isn't a readable image now adds a link card instead of a broken image.

### Before updating

- Agents connected to 0.2.0 should reconnect to pick up the new tools. `read_active_canvas` is now `read_canvas`.
- Desktop installers are unsigned. macOS may require right-click Open; Windows may show SmartScreen on first launch.
