Cadanraw 0.2.2 makes connecting Claude a one-time, one-click step.

### Easier agent setup

- **Add to Claude Desktop** and **Add to Claude Code** buttons in **Connect → Agent access**. Claude Desktop gets Cadanraw added to its config (your other servers are kept); Claude Code gets it registered for all projects.
- Cadanraw now ships a local (stdio) MCP bridge, the same kind of setup Claude Desktop uses for local tools. It runs from the Cadanraw app itself, so no Node install or terminal command is needed.
- **Set up once:** agent access stays on between launches, and the setup keeps working after restarts. Previously every restart changed the port and token and broke the saved config.
- If Cadanraw is closed, agents still see its tools and get a clear message to open the app, instead of a broken connection.
- **Other apps** has a copyable local config, the direct HTTP config (now including `"type": "http"`), and a button to reset the HTTP token.

### Before updating

- Claude Code users who added Cadanraw by hand: choose **Add to Claude Code** once; it replaces the old entry.
- Claude Desktop's **Add custom connector** dialog is for public HTTPS servers and can't reach apps on your computer. Use **Add to Claude Desktop** instead.
- On Windows, **Add to Claude Code** copies the command to paste into a terminal.
- Desktop installers are unsigned. macOS may require right-click Open; Windows may show SmartScreen on first launch.
